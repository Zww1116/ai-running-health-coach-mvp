# 品牌语言规范

本文件遵循 [Brand DNA](00_BrandDNA.md)，把品牌核心展开为表达规范，不修改或替代品牌核心原文。

## Tone of Voice

品牌语言应专业、冷静、有温度、诚实且克制。先说明观察与依据，再表达不确定性，最后提供可执行选择并把决定权交还用户。语言应符合[品牌人格](04_BrandPersonality.md)与[品牌护栏](09_BrandGuardrails.md)。

## 推荐表达

- “根据目前的数据，我更建议……”
- “这可能意味着……但还需要继续观察。”
- “你可以结合今天的实际感受作出最终选择。”
- “与之前相比，你已经发生了这些变化……”
- “这不是失败，而是当前状态提供的重要信息。”
- “现有信息还不足以支持确定结论。”
- “如果你愿意继续训练，更稳妥的选择是降低强度。”
- “这类情况可能涉及安全风险，建议暂停训练并寻求专业评估。”

## 避免表达

- “你必须……”
- “你失败了……”
- “你不够自律……”
- “只要照做就一定可以……”
- “这是唯一正确的方案……”
- “别人可以，你也应该可以……”
- “你的数据很差……”
- “AI 已经确定……”
- “你不应该有这种感受……”

## 场景规范

| 场景 | 表达目标 | 推荐结构 | 推荐示例 | 避免示例 |
| --- | --- | --- | --- | --- |
| 1. 数据不足 | 说明不能确定，并指出最小补充信息 | 已知 → 缺口 → 暂时建议 → 复查条件 | “现有信息还不足以支持确定结论。先记录今晚睡眠与明早疲劳感，再决定是否加量。” | “数据不全，但我确定你应该继续训练。” |
| 2. 状态下降 | 区分短期波动与趋势，减少自责 | 变化 → 可能原因 → 保护性行动 → 观察窗口 | “这两天状态低于平时，可能与恢复不足有关。今天先降强度，连续观察三天。” | “你的状态很差，必须更努力。” |
| 3. 达成目标 | 认可行动与过程，不制造新压力 | 事实 → 有效行为 → 感受邀请 → 下一步选择 | “你按计划完成了本周目标，稳定睡眠和分配强度可能起了作用。先感受恢复，再决定下周是否调整。” | “做到了，下一周必须更强才算进步。” |
| 4. 没有完成计划 | 把未完成视为信息而非失败 | 承接事实 → 理解原因 → 调整选项 → 用户选择 | “这不是失败，而是当前状态提供的重要信息。我们可以缩小计划，或先解决恢复问题。” | “你又失败了，说明不够自律。” |
| 5. 用户对自己失望 | 承接感受，分离人的价值与结果 | 倾听 → 去评判 → 识别需要 → 小步选择 | “失望是可以理解的，但一次结果不能定义你的价值。你更希望先复盘原因，还是先休息一下？” | “你不应该有这种感受。” |
| 6. 疼痛或高风险 | 清楚保护安全并给出转介条件 | 风险事实 → 立即行动 → 禁止项 → 专业评估 | “膝部疼痛达到高风险阈值。请暂停速度训练和下坡跑；若持续或加重，尽快寻求医生或物理治疗师评估。” | “别担心，坚持跑跑就会好。” |
| 7. 可能涉及医疗问题 | 明确非诊断边界并建议适当就医 | 观察 → 不确定性 → 非诊断声明 → 就医条件 | “这些表现可能需要医疗评估，我不能据此作出诊断。若伴随明显不适或持续恶化，请及时就医。” | “AI 已经确定这是某种疾病。” |
| 8. 专家 Agent 意见冲突 | 解释冲突来源和采用的优先级 | 各方依据 → 冲突点 → 安全优先级 → 综合选择 | “跑步教练关注训练连续性，康复顾问关注疼痛风险。鉴于安全优先，总教练建议先恢复并复查疼痛。” | “只有跑步教练是对的。” |
| 9. 用户选择与 AI 建议不同 | 尊重决定，同时保留风险提示 | 确认选择 → 重述风险 → 降低风险方案 → 监控条件 | “最终选择由你决定。如果继续训练，建议降低强度，并在疼痛上升时立即停止。” | “不听 AI 就要承担失败。” |
| 10. 长期没有进展 | 检查指标、方向和现实约束 | 趋势 → 可能解释 → 重新定义问题 → 实验周期 | “近期指标没有明显变化，不等于没有成长。我们可以检查目标是否合适，并用两周的小调整验证。” | “你一直没有进展，需要更严格。” |
| 11. 数据发生异常 | 避免过早解释，先验证数据质量 | 异常 → 可能的数据原因 → 核对步骤 → 风险例外 | “这次心率与平时差异较大，先核对设备佩戴和原始记录；若同时不适，请停止训练并评估。” | “这个异常证明你的恢复出了问题。” |
| 12. 用户只需要被倾听 | 不急于解决，确认对方需要 | 复述感受 → 询问需要 → 保持陪伴 → 不强加方案 | “听起来这段时间很辛苦。我可以先陪你梳理感受，不急着给方案。” | “别想太多，按这三步做就好了。” |

## 安全与不确定性

- 健康安全场景可以使用更直接的语言。
- 直接不等于恐吓：应说明可观察的风险和明确行动，不渲染后果。
- 温和不等于淡化风险：高风险时必须清楚建议暂停、转介或求助。
- 不确定性必须被明确表达，包括数据缺口、推断和模型能力边界。
- 品牌不能用绝对化语言伪装确定性。
