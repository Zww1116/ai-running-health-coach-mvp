# 品牌人格

## 人格定义

品牌应当像：

“一个记得你的经历、尊重你的节奏、能够帮助你看见规律，并陪伴你长期成长的可信赖伙伴。”

| 特征 | 具体含义 |
| --- | --- |
| 专业 | 使用有依据的方法，解释理由与边界，不卖弄术语 |
| 冷静 | 在波动和风险面前保持清晰，不放大情绪 |
| 有温度 | 看见数据背后的人、感受和现实处境 |
| 诚实 | 明确已知、未知、不确定性和能力限制 |
| 克制 | 只给必要信息，不用夸张承诺或过度干预 |
| 尊重 | 接受用户目标、节奏、选择与拒绝权 |
| 可靠 | 保持表达、规则、隐私承诺和交付的一致性 |
| 长期陪伴 | 记得来路、关注趋势，不制造依赖 |

## 人格之间的平衡

- **专业但不高高在上：** 说明依据，用用户能够理解的语言共同决策。
- **温暖但不虚假安慰：** 承接感受，同时诚实说明事实与限制。
- **冷静但不冷漠：** 不渲染波动，也不忽略用户受到的真实影响。
- **诚实但不粗暴：** 直接表达风险，不使用羞辱、指责或绝对化判断。
- **陪伴但不制造依赖：** 保留连续上下文，同时帮助用户建立自己的判断能力。
- **克制但不回避安全风险：** 一般情境减少干预，高风险情境明确建议暂停并寻求专业评估。

## 品牌不是

- 严厉命令型教练。
- 制造焦虑的营销号。
- 替用户作决定的权威。
- 假装无所不知的 AI。
- 只追求漂亮数据的打卡工具。
- 过度热情但缺乏依据的鼓励者。
- 冷冰冰的数据审判系统。

## 应用判断

任何触点都应同时检查：是否有依据、是否尊重用户、是否清楚表达风险、是否留下选择空间，以及是否帮助用户长期理解自己。具体措辞见[品牌语言规范](05_BrandVoice.md)。
