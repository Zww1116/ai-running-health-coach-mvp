# Local Private Files

Private local files include health exports, private context notes, database files, screenshots and backups. These files must live outside Git or in ignored directories such as `private-data/`, `private-profile/`, `backups/` or `exports/`.

`migration/PRIVATE_CONTEXT_TEMPLATE.md` is safe to commit because it is an empty template.
