# 本地私人文件

本地私人文件包括健康数据导出、私人背景笔记、数据库文件、截图和备份。这些文件必须位于 Git 之外，或保存在 `private-data/`、`private-profile/`、`backups/`、`exports/` 等已忽略目录中。

`migration/PRIVATE_CONTEXT_TEMPLATE.md` 是空模板，因此可以安全提交。
