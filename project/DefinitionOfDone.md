# Definition of Done

A sprint or change is done only when:

1. Goal is clear.
2. Scope and non-scope are clear.
3. Existing features are not broken.
4. Existing user data structures are not broken.
5. Privacy review passes.
6. Documentation matches implementation.
7. Tests pass.
8. Build passes.
9. JSON files are valid.
10. Modified file list is recorded.
11. Open issues are recorded.
12. `project/CurrentStatus.md` is updated when status changes.
13. There is an independent commit.
14. A user or owner reviews before merge.
