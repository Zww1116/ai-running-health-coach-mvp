# 文件管理规则

1. 每类资产只有一个正式来源。
2. 不要把临时文档放在仓库根目录。
3. 避免使用 `final`、`latest`、`final2`、`new`、`copy` 或 `temporary` 等命名。
4. 文件名使用稳定、清晰的英文。
5. 在适合创始人阅读的场景中，正文以中文为主。
6. 每个 Sprint 都有独立记录。
7. 重大决策使用 ADR。
8. 失效文件移入 `archive/`。
9. 删除文件前先记录其替代关系。
10. README 不重复维护详细规则。
11. 健康数据不得进入 Git。
12. 私人导出不得进入 Git。
13. Schema 变更必须提升 Schema 版本。
14. Prompt 变更必须记录 Prompt 版本。
15. Agent 规则变更必须记录 Agent 版本。
16. AI 聊天不是正式结论。
17. 只有创始人确认后，内容状态才能从 `proposed` 变为 `approved`。
