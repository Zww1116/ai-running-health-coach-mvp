# Project Governance

This directory stores the project operating system: current status, roadmap, backlog, source-of-truth rules, decision records, sprint records and templates.

It does not store private health records, API keys, database exports, images, temporary notes or unreviewed chat transcripts.

The current formal source for governance is this directory, with [PROJECT.md](../PROJECT.md) acting as the top-level entry point.

Changes should be made through a focused sprint, recorded in `project/sprints/`, and reviewed before merge.
