# 项目治理

本目录保存项目的治理体系：当前状态、路线图、Backlog、唯一正式来源规则、决策记录、Sprint 记录和模板。

本目录不保存私人健康记录、API 密钥、数据库导出、图片、临时笔记或未经审阅的聊天记录。

当前治理内容的正式来源是本目录，[PROJECT.md](../PROJECT.md) 作为顶层入口。

当前项目阶段、当前 Sprint、审核状态与下一步只由 [CurrentStatus.md](CurrentStatus.md) 定义。其他治理文件记录规则、历史或范围，不独立定义当前状态。

变更应通过范围聚焦的 Sprint 完成，记录在 `project/sprints/`，并在合并前接受审阅。
