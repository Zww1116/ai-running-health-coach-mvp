# ADR-0004：仓库可见性与许可证

## 状态

`Approved`。

## 背景

当前公开部署依赖可访问的网站和公开仓库，但源代码、品牌、Prompt、Agent 与产品设计属于需要长期保护的核心源资产。私人健康数据与公开项目资产必须保持严格分离。

## 决策

- 公开部署的网站可以继续访问。
- 私人健康数据不得公开，也不得进入 Git。
- 源代码、品牌、Prompt、Agent 和产品设计长期以私有源资产管理为目标。
- 当前公开仓库属于过渡状态；本次 PR 不立即修改仓库可见性或部署方式。
- 当前不添加开源许可证。未经创始人另行批准，默认保留全部权利。
- 未来迁移到私有仓库前，必须先验证公开部署、Codex 访问和备份恢复流程。
- Codex 不得自行修改仓库可见性、部署方式或许可状态。

## 理由

该过渡方案在不中断公开网站和现有协作流程的前提下，明确私人数据边界与长期源资产保护方向。先验证部署、Codex 访问和备份，再迁移仓库，可降低服务中断或资产丢失风险。

## 备选方案

立即将仓库设为私有，或现在添加开源许可证。两项方案当前均不采用：前者尚未完成部署与访问验证，后者不符合默认保留全部权利的决定。

## 正面影响

保持公开网站可访问，同时确立长期私有源资产方向、私人数据红线和默认权利边界。

## 负面影响

过渡期间公开仓库仍会暴露代码与产品思路，迁移私有仓库的具体时间尚未确定。

## 风险

访问者可以查看当前公开仓库，但项目不授予开源复用许可。公开可见不等于开放授权；仍需避免在公开资产中泄露私人数据、密钥或未准备公开的核心资料。

## 复审条件

在迁移私有仓库、改变部署方式、增加协作者、商业化、授权复用或开源发布前复审。迁移前必须记录并通过部署、Codex 访问和备份验证。
