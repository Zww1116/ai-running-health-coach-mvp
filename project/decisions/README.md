# 架构决策记录

本目录保存重大项目决策及其理由。当决策被替代时，应更新对应 ADR；当满足其复审条件时，应重新审阅。

ADR 的 `status` 表示该项决策自身的成熟度，不表示当前 Sprint 或项目阶段。当前项目状态只以 [project/CurrentStatus.md](../CurrentStatus.md) 为准；当前所有 ADR 继续保持 `proposed`，不得在入口文件中被描述为已批准。
