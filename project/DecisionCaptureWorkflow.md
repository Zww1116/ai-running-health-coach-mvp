# 决策记录流程

当创始人确认产品、品牌、架构或 Agent 决策时：

1. 确认唯一正式来源。
2. 只更新该正式来源。
3. 重大决策应创建或更新 ADR。
4. 如果决策改变当前状态，则更新 `project/CurrentStatus.md`。
5. 记录状态、版本、来源和日期。
6. 不要把完整聊天记录复制进仓库。
7. 在 Sprint 记录中列出修改文件。
